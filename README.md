# 세모고강 CKD Care v1.1

개·고양이 만성신장질환 검사 결과를 날짜별로 기록하고 이전 검사와 비교하며 장기 추세를 확인하는 로컬 웹앱입니다.

## 실행

가장 간단한 방법은 `index.html`을 브라우저로 여는 것입니다. 브라우저 보안 설정에 따라 다운로드 기능이 제한되면 이 폴더에서 로컬 웹 서버를 실행하세요.

```powershell
python -m http.server 4173
```

그다음 `http://127.0.0.1:4173`을 엽니다.

## 데이터 저장

- 데이터는 해당 브라우저의 `localStorage`에 저장됩니다.
- 정기적으로 앱의 **데이터 내보내기 → JSON 백업 다운로드**를 사용하세요.
- 다른 브라우저나 PC로 이동할 때 JSON 백업 파일을 복원할 수 있습니다.

## 포함된 기능

1. 반려동물 등록·수정
2. 검사수치 입력
3. 검사기록 저장·수정·삭제
4. 과거 검사 조회
5. 이전 검사 자동 비교
6. 절대 변화량·변화율 계산
7. 주요 검사수치 추세 그래프
8. 검사 기록 기간 필터와 전체 항목 상세보기
9. 이전 검사 복사와 그래프 기간별 요약
10. CSV 내보내기와 v1.0 호환 JSON 백업·복원
11. 마지막 백업일 안내와 안전한 반려동물 삭제
12. 주요 검사 항목 도움말
13. 모바일 검사 카드와 PWA 홈 화면 설치

## v1.0 데이터 호환

- 기존 `semogogang-ckd-care-v1` localStorage 키를 그대로 사용합니다.
- v1.0 데이터는 실행 시 v1.1 필드를 보존적으로 추가하여 사용합니다.
- v1.0에서 내보낸 JSON 백업도 복원할 수 있습니다.

## 의료 안전

이 앱은 기록·계산·비교·추세 확인을 위한 도구입니다. CKD 진단, IRIS Stage 자동 판정, 약물·보조제·수액 용량 결정 또는 치료 변경 지시를 제공하지 않습니다.
